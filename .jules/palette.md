## 2025-05-18 - Destructive Actions and Icon Buttons in Scheduled Tasks
**Learning:** Found that icon-only action buttons (like Delete and Pause) on scheduled tasks lacked `aria-label` attributes and keyboard focus indicators (`focus-visible`). Additionally, the destructive "Delete" action executed immediately without a confirmation prompt, which can lead to accidental data loss.
**Action:** When adding or reviewing icon-only buttons, especially in list items or repetitive components, always ensure `aria-label` and `focus-visible` classes are present. For any destructive actions (like delete), ensure a confirmation mechanism (like `window.confirm`) is in place.
## 2024-05-24 - Loading states and `lucide-react`
**Learning:** `RefreshCw` with `animate-spin` is the established, clean pattern for loading spinners in this React application utilizing Tailwind and `lucide-react`. Replacing default static icons (e.g., `Send`) with this spinner during asynchronous operations (like `isSending` or `isLoggingIn`) provides excellent immediate visual feedback and improves perceived performance, especially important when UI updates are blocked by Firebase auth popups.
**Action:** When creating interactive elements that trigger network requests, ensure they have explicit loading states bound to their associated `isLoading` boolean. Prefer inline icon replacement over structural layout shifts to prevent UI jumping.
