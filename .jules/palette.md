## 2025-05-18 - Destructive Actions and Icon Buttons in Scheduled Tasks
**Learning:** Found that icon-only action buttons (like Delete and Pause) on scheduled tasks lacked `aria-label` attributes and keyboard focus indicators (`focus-visible`). Additionally, the destructive "Delete" action executed immediately without a confirmation prompt, which can lead to accidental data loss.
**Action:** When adding or reviewing icon-only buttons, especially in list items or repetitive components, always ensure `aria-label` and `focus-visible` classes are present. For any destructive actions (like delete), ensure a confirmation mechanism (like `window.confirm`) is in place.
## 2025-06-25 - Interactive Feedback and Accessibility on Send Buttons
**Learning:** Found that primary interactive inputs, such as icon-only "Send" submit buttons in chat and channel interfaces, lacked `aria-label`s, robust keyboard focus states (`focus-visible`), and visual loading indicators. These omissions impair screen reader functionality, hinder keyboard navigation, and provide poor feedback to users during asynchronous actions.
**Action:** When working on interactive input elements and form submissions, always provide explicit `aria-label`s for icon-only buttons, add standard `focus-visible` styling (e.g., `focus-visible:ring-2`), and incorporate clear visual feedback (like a spinning icon) when operations are in an asynchronous loading or sending state.
