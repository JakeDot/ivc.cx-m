## 2025-05-18 - Destructive Actions and Icon Buttons in Scheduled Tasks
**Learning:** Found that icon-only action buttons (like Delete and Pause) on scheduled tasks lacked `aria-label` attributes and keyboard focus indicators (`focus-visible`). Additionally, the destructive "Delete" action executed immediately without a confirmation prompt, which can lead to accidental data loss.
**Action:** When adding or reviewing icon-only buttons, especially in list items or repetitive components, always ensure `aria-label` and `focus-visible` classes are present. For any destructive actions (like delete), ensure a confirmation mechanism (like `window.confirm`) is in place.
## 2025-05-18 - Missing Accessibility Attributes on Async Form Submit Buttons
**Learning:** Found that the primary "Send" button in the channel chat interface lacked an `aria-label` for screen readers and `focus-visible` styling for keyboard navigation. Furthermore, while it disabled itself during submission, it did not provide a visual loading indicator, leaving users without clear feedback that their action was being processed.
**Action:** When implementing or reviewing interactive buttons, especially form submits triggering async actions, ensure they have `aria-label` attributes, use `focus-visible` ring styling for keyboard users, and provide explicit visual feedback (like a loading spinner replacing the icon) when in a loading/sending state.
